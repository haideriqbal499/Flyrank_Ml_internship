# Demo video checklist (3–5 minutes)

**Goal:** unlisted YouTube link of a **live** end-to-end run with voice narration. No slide deck.

## Record with

OBS Studio (free), Loom free, or Win+G — whatever you already have.

## Script outline (stay in this order)

| Time | Show | Say |
|---|---|---|
| 0:00–0:30 | README or Project name on screen | Who it’s for; one job: metrics → honest mentor note → I send |
| 0:30–1:00 | Project instructions (scroll) | **Design decision:** no email/send tool — overclaims are the failure mode, so draft-only |
| 1:00–3:30 | Live chat | Attach `packets/live_w05_packet.json`, type `UPDATE`, let DRAFT→CRITIQUE→REVISE finish **without editing mid-run** |
| 3:30–4:15 | Point at revised numbers | Diff out loud: 0.9 / 0.3 / 6 clients match the packet |
| 4:15–4:45 | Same chat or thin packet | **Limitation on camera:** thin packet or “no auto-send” — pick one and show it |
| 4:45–5:00 | Stop | “Human must re-check before send” on screen |

Keep total **3:00–5:00**. If long, cut the README scroll, not the live run.

## Limitation options (pick one to show)

- Thin packet refuse: `UPDATE` + `{"model":"random_forest"}`  
- Or say clearly: agent never emails — I must copy-paste (show you not clicking send in Gmail)
